# Punos

Punos is a suite of home automation devices.

This is a learning project and work in progress.

The goal of the project is learning while building useful devices. Learning
areas include electronics design, KiCad, electronics assembly by hand tools,
what is possible and what is not in electronics, microcontroller capabilities
and firmware develpment.

Design drivers, in no particular order:
- Devices should be useful to me
- Devices are battery powered when it makes sense, with a long battery life
- Wireless communication range should cover ~30-50 m, from building to building
- PCBs are cheap to manufacture
- Components are relatively cheap
- Firmware is written in Rust

See [hardware](hardware/) for currently released boards.
